## 🌐 Language Translation Tool

A simple multilingual translation web app built with Python, Gradio, and LibreTranslate.

### Features

* 🌍 Translation between 50 languages
* 🔽 From/To language dropdowns
* ↔️ Side-by-side input and translation
* 🔊 Text-to-speech for supported languages
* 💾 Audio download
* 📋 Copy text

### Technologies

* Python
* Gradio
* LibreTranslate REST API
* gTTS (Google Text-to-Speech)

### How it works

User → Gradio UI → LibreTranslate REST API → Translation → Gradio UI
