# E-Commerce FAQ Chatbot

An NLP-based FAQ chatbot that matches customer questions with the most relevant e-commerce FAQ and returns the corresponding answer.

## Tools & Technologies
- Python
- Google Colab
- Pandas
- NLTK
- Sentence Transformers (`all-MiniLM-L6-v2`)
- Cosine Similarity
- Gradio

## Dataset
E-Commerce FAQ dataset containing 79 questions and answers.

**Dataset Link:** [GitHub Dataset]
https://raw.githubusercontent.com/imsoumya18/E-commerce_FAQ/main/Ecommerce_FAQs.csv

## Features
- NLP text preprocessing
- Semantic FAQ matching
- Cosine similarity
- Confidence threshold (0.60)
- Interactive Gradio interface
